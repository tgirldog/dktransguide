# DIY Sources

Purchasing DIY hormone therapy can feel overwhelming, as there are many different sellers, all of whom frequently face stock shortages. Below are the two primary sites that track which sellers currently have hormones in stock. I recommend keeping an eye on these sites to find sellers with available inventory.

- [valerie.vg](https://valerie.vg/) – Valerie is my go-to. I highly recommend it.
- [diyhrt.coffee](https://diyhrt.coffee/) – Also a fantastic site, but it is short on funds. Please [donate](https://diyhrt.coffee/donate) if you can.

These sites only provide information on where to buy feminizing hormones. For information on masculinizing hormone therapy, see [diyhrt.info](https://diyhrt.info/transmasc/sources/).
